Thực hành nền tảng JavaScript, thao tác DOM, xử lý sự kiện,
kiểm tra biểu mẫu và sử dụng jQuery.

## Nội dung

- Lab08: 11 Exercise về JavaScript, Console, mảng, hàm và object.
- Lab09: 8 Exercise về DOM, sự kiện, debugger và biểu mẫu.
- Lab10: 10 Exercise về jQuery, hiệu ứng, GET và jqXHR.

Lab 10.1 và 10.2 dùng chung trang theo bộ mã thực hành.

Các bài đã được chạy thử trên Chrome qua Live Server,
kèm ảnh minh chứng trong thư mục minh-chung.

Đã mở thử các liên kết Exercise từ trang chủ trên máy cục bộ,
chưa ghi nhận lỗi 404 trong lần kiểm tra này.
GitHub Pages sẽ được kiểm tra riêng sau khi push.

Bài 10.9–10.10 tải JSON mẫu thành công.
Ca đường dẫn sai ở bài 10.10 trả HTTP 404.
Lần thử dịch vụ giáo trình ở bài 10.10 gặp HTTP 0, error;
chưa xác định nguyên nhân.
